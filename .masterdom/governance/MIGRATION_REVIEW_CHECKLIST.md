# Migration Review Checklist

- [ ] Clean working tree
- [ ] Build succeeds
- [ ] Affected tests pass
- [ ] Migration contains only intended schema changes
- [ ] Snapshot reviewed
- [ ] No unrelated module changes
- [ ] Migration file is non-empty
- [ ] `Up` and `Down` changes were reviewed
- [ ] Validation script passed
- [ ] Reviewer confirmed the change is traceable
