# Milestones

## Milestone Structure

Each milestone must define:

| Field           | Description                                                         |
| --------------- | ------------------------------------------------------------------- |
| Objective       | The outcome the milestone is intended to achieve                    |
| Entry Criteria  | The conditions required before work begins                          |
| Exit Criteria   | The conditions required before the milestone is considered complete |
| Validation Gate | The required validation steps for the milestone                     |
| Current Status  | The current lifecycle state of the milestone                        |
| Completion Date | The date on which the milestone was completed, if applicable        |

## Milestone Lifecycle

| Status    | Meaning                                                   |
| --------- | --------------------------------------------------------- |
| Proposed  | The milestone exists as a candidate only                  |
| Planned   | The milestone is approved and queued                      |
| Active    | The milestone is currently being delivered                |
| Completed | The milestone has met exit criteria and been closed       |
| Deferred  | The milestone is intentionally postponed                  |
| Cancelled | The milestone is no longer planned and remains in history |

## Milestones

### Foundation

| Field           | Value                                                                            |
| --------------- | -------------------------------------------------------------------------------- |
| Objective       | Establish shared governance, core domain foundations, and program-wide standards |
| Entry Criteria  | Baseline repository structure exists                                             |
| Exit Criteria   | Governance structure and foundational domain kernels are established             |
| Validation Gate | Required build and documentation checks for the active workstream                |
| Current Status  | Active                                                                           |
| Completion Date | Not yet completed                                                                |

### Future Milestones

Future milestones will be defined at the time they become active. They should not be expanded in detail until they enter the delivery queue.
